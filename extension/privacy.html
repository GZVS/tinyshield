TinyShield Privacy Policy

Effective date: 10 October 2026 Extension version: 3.1.1 Developer: GZVS — GZ - Your friendly developer Contact: zsgeorgios@icloud.com

What TinyShield does

TinyShield blocks selected ad and tracker requests using packaged Chromium Declarative Net Request rules. Optional adult and gambling filters match the hostname of top-level website navigations against bundled domain lists and redirect matching requests to a local TinyShield blocked-site page before the website loads. Optional page cleanup hides common ad placeholders with packaged CSS. An optional YouTube network filter is experimental and best effort.

Information processed on your device

Your browser matches request URLs and domains locally to apply TinyShield's network rules. The extension does not receive or record a browsing-history feed or blocked-request log. When page cleanup is enabled, a local helper reads the current page hostname in memory to honor allowed websites and sets a page attribute so packaged CSS can hide matching ad placeholders. It does not collect page text, form fields, passwords, or audio. The blocked-site page shows only the category; it does not store or display the original URL.

Local storage and retention

TinyShield stores your filter preferences, allowed website domains, and current filter-application status in chrome.storage.local in this browser profile. It does not use account sync, cloud storage, cookies, or local browsing logs. Preferences are shared between normal and private windows in this profile, while the extension uses split private-window execution when you explicitly allow it in Incognito/InPrivate. Preferences remain until you change them or remove the extension. The Test blocking screen stores only a reserved test-tab ID, category, test type (local page or redirect), start time and pass/unconfirmed result in chrome.storage.session; normal and private windows use separate test-state keys; these diagnostic results disappear when the browser session ends or the extension is reloaded/updated. Normal blocked visits are not logged. Export diagnostics creates a JSON file on your device only when you click the export button; it contains filter checks and test results, without browsing URLs or the test-tab ID. The export identifies whether the check ran in a normal or private window. You can remove individual allowed domains in Settings. Uninstalling TinyShield removes its extension-managed local settings from the browser; copies of the extension files you saved separately are unaffected.

Transmission, sharing and tracking

TinyShield has no developer-operated backend, analytics, advertising SDK, telemetry, or automatic filter-list downloader. It does not send your browsing activity or settings to the developer or any server, sell personal data, or use browsing data for advertising. Blocklists are shipped inside the extension and refreshed through extension releases. Chrome or Microsoft Edge handles its own extension installation and update services under the browser provider's policies.

Permissions

  • declarativeNetRequest: applies packaged ad, tracker and category rules, plus user-selected exceptions.
  • storage: saves local preferences, allowed websites and filter status, plus temporary session-only blocking-test state.
  • scripting: registers the packaged helper and CSS when optional page cleanup is enabled.
  • sidePanel: offers TinyShield's controls next to a webpage; the toolbar action otherwise opens the compact popup.
  • Optional HTTP/HTTPS website access: required to redirect a listed website to TinyShield's local blocked page and to run page cleanup. Your browser asks when you enable those features. You can revoke access in your browser's extension settings; TinyShield turns the dependent features off. Basic ad and tracker blocking does not require granting this optional access.

TinyShield does not request tabs, history, webRequest, or declarativeNetRequestFeedback permissions. Its use of chrome.tabs creates a harmless reserved test tab and navigates that tab to a local blocked-page check or to adult.tinyshield.test or gambling.tinyshield.test at your request. It does not read browsing URLs. The sidebar uses the current window ID, and Go back falls back to local Settings if there is no prior page.

Security and your choices

TinyShield contains no remotely executed code and has a restrictive extension Content Security Policy. Filtering and preferences stay local. You can pause all filters, disable categories separately, remove website exceptions, revoke optional website access, or uninstall the extension. Website exceptions bypass all TinyShield filters for that domain and its subdomains. This is not a locked parental-control or tamper-resistant product. No domain list guarantees complete coverage.

Policy changes

This document will be updated when TinyShield's data handling changes. The effective date and extension version identify the policy applicable to a release. Updates are supplied with the extension and at the public policy URL used in its store listing.
