Zenith Guard Privacy Policy

Effective date: 14 October 2026 Extension version: 3.2.0 Developer: GZVS Contact: zsgeorgios@icloud.com

What Zenith Guard does

Zenith Guard blocks selected ad, tracker and malicious requests using packaged Chromium Declarative Net Request rules. Optional adult, gambling, and security filters match the hostname of top-level website navigations against bundled domain lists and redirect matching requests to a local Zenith Guard blocked-site page before the website loads. Packaged CSS hides ad placeholders, and modern YouTube shielding auto-skips video advertisements without tracking or cloud dependencies.

Information processed on your device

Your browser matches request URLs and domains locally to apply Zenith Guard's network rules. The extension does not receive, transmit, or record browsing history feeds or blocked request logs. When cosmetic filtering is enabled, a local content script reads the current page hostname in memory solely to honor allowed websites. It does not collect page text, form fields, passwords, or personal data.

Local storage and retention

Zenith Guard stores your filter preferences, allowed website domains, and current filter-application status in chrome.storage.local in this browser profile. It does not use account sync, cloud storage, cookies, or local browsing logs. Preferences are shared between normal and private windows in this profile. All settings remain strictly local until you change them or remove the extension.

Transmission, sharing and tracking

Zenith Guard has no developer-operated backend, analytics, advertising SDK, telemetry, or automatic filter-list downloader. It does not send your browsing activity or settings to the developer or any third-party server, sell personal data, or use browsing data for advertising. Blocklists are shipped inside the extension package and refreshed through extension releases.

Permissions

  • declarativeNetRequest: applies packaged ad, tracker and security rules, plus user-selected exceptions.
  • storage: saves local preferences, allowed websites and filter status.
  • scripting: supports packaged content scripts and CSS for cosmetic page cleanup.
  • sidePanel: provides Zenith Guard's controls next to a webpage in supported browsers.
  • host_permissions: allows Zenith Guard to inject local cosmetic CSS and perform client-side security redirects without runtime permission prompts.

External links and donations

The GitHub button opens https://github.com/GZVS. The optional donation button opens https://www.paypal.com/paypalme/Zacharidis. These links pass no data, use strict no-referrer policies, and never navigate automatically.

Security and your choices

Zenith Guard contains no remotely executed code and has a restrictive Content Security Policy. Filtering and preferences stay strictly local. You can pause all shields, disable categories separately, or remove website exceptions at any time.
